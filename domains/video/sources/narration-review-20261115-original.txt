根本原因在于：**`v0.3.1` 是一套极其精密的“视觉图解语法（Visual Diagramming Grammar）”，但它默认跳过了“视听叙事契约（Audio-Visual Narrative Contract）”。**

这也直接回答了你的第二个问题：**不需要去泛泛搜索更多的“做视频技巧/剪辑准则”来增加原语数量。** 市面上的视频制作准则（如 J-cut/L-cut、三分法构图、景别切换节奏、黄金前三秒）绝大多数属于你五层架构里的**第四层（风格）**和**第五层（实现）**——把它们塞进第二层（原语），只会把体系再次弄脏。

真正需要补的，不是新的视觉动作，而是在原语执行之前加一道“声画锁定前置门禁（Gate 0）”——这背后对应的，是认知心理学与纪录片/知识视频剪辑中早已成熟的 **4 条跨模态基础公理**。

以下为你完整梳理这次“高精尖体系栽在基础问题上”的四大系统性病根，以及架构收敛方案。

### 一、 深度复盘：为什么原语系统没拦住这 6 处基础错误？

这套系统连“投机采样的正残差分布”和“DDP 通信桶的 GPU Kernel 重叠”都能严密建模，却漏掉了“嘴里说改模板、屏幕上写 20 页课件”，背后有四个结构性原因：

#### 1. 视野盲区：重“图内拓扑（Visual-to-Visual）”，轻“声画接口（Audio-to-Visual）”

* **现状：** 现有的 11 个入口（定焦、对应、编组、串联、保持身份、锁定参照、改变尺度、留停、证据落地、时间关系、对齐比较），**90% 的笔墨都在规范“画面内部元素之间的关系”**（比如框怎么画、箭头怎么连、两条泳道怎么对齐）。
* **盲区：** 在知识播客和讲解视频中，观众的第一信息主轴不是画面，而是**耳朵听到的语音流**。现有系统默认假设：“分镜师放进画面的文字已经是核对过原声的正确文字”，结果在 `#2 对应（video.correspond）` 中只管了“头像对说话人”、“引线对端子”，却漏掉了全片最高频的映射——**“当前 3 秒主播口述的词句 $\leftrightarrow$ 屏幕卡片上的标题与核心字”**。一旦两者出现字面或情绪极性（痛点 vs 解法）偏差，大脑就会产生强烈的**斯特鲁普干扰（Stroop Interference，听到的词和看到的字打架）**。

#### 2. 制作流程倒置：`GUIDE.md` 把“定关系”排在“锁原声”之前

* **现状：** 看 `GUIDE.md` 的《一次制作的六步》：
> `1. 取材料 → 2. 定关系 → 3. 选最少动作 → 4. 定关键画面与时序 → 5. 再定风格与实现 → 6. 分别检查`


* **盲区：** 在知识播客这种“先有对谈原声、后配视觉解释”的体裁里，如果你跳过“逐句锁定原声语义切片”，直接去“定关系、选动作”，制作 Agent 就会站在上帝视角（看完整期节目的大纲后），把 15 分钟后的结论提前画在 00:41 的痛点上，或者凭空编造自己顺手的文案（如把“改格式”脑补成“20 页课件”）。

#### 3. 时间轴维度缺失：有“物理并发时间”，无“叙事因果时间（防剧透律）”

* **现状：** `v0.3.1` 刚刚补上了 `video.temporal-relations`（处理同一时间段内多路事件的并发与积压）和 `video.hold`（处理观众阅读静止时长），但这两种时间都是**局部画面内部的时间**。
* **盲区：** 整个视频在宏观上是一条**单向推进的叙事因果链**。一个具体案例（如“课件改不了字”）、一个解法（如“回到最初问题”），在主播用嘴说出来之前，在观众的认知世界里是**尚未诞生**的。现有系统缺少一条硬性时间不等式约束：**视觉对象的首次曝光时刻 $t_{\text{visual}}$ 必须大于或等于原声首次引入该对象的时刻 $t_{\text{audio}}$（$t_{\text{visual}} \ge t_{\text{audio}}$）**。

#### 4. 工程隔离失败：方法库里的“脱敏合成示例”污染了下游制作 Agent

* **现状：** 你的文档规范极度严谨——为了不捏造原片事实，你在 `PODCAST-PATTERNS.md` 中刻意自己编写了“20 页课件”、“社会心理学从众”、“冰淇淋与游泳人数”作为方法演示示例，并在页首写了免责声明。
* **盲区：** 本地制作 Agent 在读取工作区并生成视频组件时，**把方法仓库的 `PODCAST-PATTERNS.md` 当成了本集播客的组件内容库**，直接把示例文案（“改成 20 页课件”）和虚假背景（“冷饮与游泳”）编译进了成片；更糟的是，当镜头切入四窗局部放大读字时，原本只是占位符的假案例瞬间变成了主注意焦点，直接导致全片题材精神分裂。

### 二、 需不需要去搜索做视频的准则来补全原语？

**结论：不需要去广撒网搜索“做视频准则”，但需要直接引入 4 条认知科学与纪录片剪辑的底层公理，作为原语系统的“声画锁定规则”。**

原因很简单：如果你去搜“知识视频制作准则”，搜出来的通常是：

* *“每 5-8 秒切换一次景别以维持注意力”*（这是粗暴的短视频留存套路，与你追求的“安静、克制、按语义决定动静”完全背道而驰）；
* *“使用动态字幕、音效转场、B-roll 铺满画面”*（这属于风格层与实现层，直接违背你的“降低竞争”原则）。

你这套原语体系真正的理论底座，是**教育心理学中的「多媒体学习认知理论（Cognitive Theory of Multimedia Learning, Richard Mayer）」**与**纪录片/科学传播的「视听证据律」**。我们只需要把其中最核心的 **4 条跨模态公理** 吸收进你的规范，就能彻底封死所有低级错误：

| 引入的经典准则（来源） | 核心原理 | 转化为你的视频系统硬规则（解决哪类错误） |
| --- | --- | --- |
| **1. 一致性原则**<br>

<br>*(Coherence Principle, Mayer)* | 当多媒体材料中加入无关的词语、图像或背景案例时，会严重挤占工作记忆，损害核心理解。 | **【全片题材同域律】** 任何用于演示过载、拆解或对比的示例文本，必须 100% 隶属于当前主线叙事的真实主题（如《当代中国科技》）；严禁在任何角落出现无关领域的占位假案例（如“冷饮与游泳”）。 |
| **2. 时间接近与叙事现身律**<br>

<br>*(Temporal Contiguity & Show-on-Mention)* | 对应的词语与画面必须同步呈现，而非先后割裂；在讲解型影像中，视觉对象应随话语提及而“现身”。 | **【严禁提前剧透律 $t_{\text{visual}} \ge t_{\text{audio}}$】** 除全片总目录外，任何具体案例或后文解法，严禁早于原声首次提及它的时间点上屏；且画面卡片的情绪极性（痛点/疑问/解法）必须与当前语音严格同构。 |
| **3. 双通道同模态干扰抑制**<br>

<br>*(Modality & Redundancy Control)* | 人类的听觉文字与视觉文字最终汇入同一个语言工作记忆通道；若耳朵听一套词、眼睛读另一套不同措辞的句子，认知解码会立即瘫痪。 | **【声画字面锚定律】** 随话音同步弹出的卡片关键词，必须直接提取自当前 3 秒内原声的实词（说“改格式/改模板”就写“改格式/改模板”）；经过编辑改写的长句模板，必须推迟到话落后的独立留停拍再整卡亮出。 |
| **4. 承诺-兑现对称律**<br>

<br>*(Set-Completion Symmetry)* | 当听觉通道给出明确的结构预期（如“今天聊三个问题”），视觉通道若只给出局部子集，会造成悬置的认知期待。 | **【集合数量守恒律】** 原声报出 $N$ 项并列议题时，画面必须在同一时间窗内兑现 $N$ 项结构的完整概览，不得用其中第 1 项的局部细节图替代全局目录。 |

### 三、 架构收敛：如何在 `v0.4.0` 中把“声画锁定”无缝嵌入现有体系？

不需要推翻你已经打磨得非常成熟的 **10 个原语 + 1 个组合入口**，只需在结构上做一次“从一维视觉排片，升级为二维声画锁死”的轻量级重构：

#### 1. 在 `GUIDE.md` 的工作流最前端，插入「第 0 步：声画语义锁定（Audio-Visual Lock）」

在原有的 `1. 取材料 → 2. 定关系 → 3. 选最少动作` 之前，强制加入一道前置工序：

* **第 0 步：逐句切片与声画锚定。**
* 先把音轨按语义话轮切成若干时间窗 `[t_start, t_end)`；
* 为每个时间窗标出**原声逐字关键词**、**语义极性（痛点 / 疑问 / 方案 / 结论）**以及**首次提及的概念清单**；
* **铁律：** 后续所有原语（`focus`、`correspond`、`group` 等）只能在当前时间窗已解锁的概念池内调度视觉元素，严禁跨时间窗提前调用未提及的案例，严禁修改原声核心实词。



#### 2. 在 `PRIMITIVES.md` 中做三处精准归位（不增加原语总数）

* **归入 `#2 对应（video.correspond）`：** 明确“声画对应”是所有对应的第一顺位——包含**字面实词锚定**、**语义极性同构**（痛点配痛点、解法配解法）以及**数量对称**（听觉报 3 项，视觉出 3 项）。
* **归入 `#6 保持身份（video.identity-preserve）`：** 补充“全片案例题材身份一致”，规定长叙事中所有嵌套窗口、样片草稿必须继承主线任务的真实主题域，并给方法文档中的所有示例打上 `[META_EXAMPLE_DO_NOT_RENDER]` 隔离标记。
* **归入 `#9 留停成像（video.hold）`：** 补充“话轮过界强制清场（Hold Expiration）”**与**“因果剧透禁令（$t_{\text{visual}} \ge t_{\text{audio}}$）”，规定当说话人切换到对立路线或下一命题时，上一张总结卡必须退场或退为明确标注归属的旧参照。

#### 3. 在 `check.py` 机器校验器中，增加 `audio_anchor` 拦截器

本地 Agent 之所以会犯错，是因为之前的 JSON 分镜结构里**没有强制要求填写“这一秒主播嘴里说的原话”**。只要在分镜 Schema 的每个屏幕文字事件上加上四个校验字段，机器就能自动抓出你排查出的全部 6 类错误：

* `audio_verbatim_slice`（必填：对应时间窗的原声逐字稿，防凭空编造）
* `audio_polarity`（必填：`pain_point | question | proposal | conclusion`，必须与 `visual_polarity` 一致，防痛点配解法）
* `first_audio_mention_sec`（必填：该案例在全片音频中首次被提及的秒数，强制校验 `visual_start >= first_audio_mention_sec`，防提前剧透）
* `episode_topic_domain`（必填：与全片主线题材哈希一致，防“冷饮与游泳”串戏）

你之前的 `v0.3.1` 已经把“如何用最精确的视觉语言讲清复杂逻辑”**做到了极高水准；而这次你在审片中揪出的 6 处音画错位，恰好帮整个系统补上了最后一块拼图——**“视觉语言必须严丝合缝地长在听觉叙事的时间轴与语义锚点上”。
