## 0.6.0 · 按感知任务选动作，按完整作品查效果

2026-11-18。根据[本轮评审原件](sources/sensory-review-20261118-original.txt)，修正静音检验范围、封装的单向输入及编号辨认，另增作品级审阅。仍为十项候选动作、两项候选组合，共十二个入口。此次改变声音与留停的适用范围及封装的输入条件，故升级为 0.6.0；未新增独立动作或改写旧 ID。

### 三处边界怎样修正

| 原问题 | 本轮改动 | 保留的相邻边界 |
|---|---|---|
| 将静音充分性套到所有任务 | 定焦、对应、证据卡和风格区分辅助声音、声音本体及听觉编码；留停可给听完与整合的机会 | 静音仍可检验视觉定位、字幕与归属；声音作为证据仍查版本、区间和处理。替代访问另验，不把文字评语当作亲耳辨认 |
| 封装只允许已解释子图作为输入 | 同一 `video.chunk` 支持“先立整体 → 首次展开 → 收回接续”和“先分后合”，用同样身份与接口双向认回 | 编辑已核内部不等于观众已懂；首次展开承担解释，不用熟悉名称冒充理解。缺少成员与关系时，动作不能自动生成机制 |
| 困难表位置被当成动作序号 | 检索表链接明确正文编号，按任务聚类顺序不变 | 编号仅用于寻址，不表示推理顺序或原语独立性 |

声音作比较材料时，定焦处理应注意哪里，对应处理声样与标签或变量映射，参照保持比较条件，时间关系表达节拍和重叠，证据落地提供可定位的真实片段；这些职责没有因换通道而自动合并。保持身份继续区分原录音与处理版，不能因同源而当成同一成品。

对封装固定相同的成员、接口、名称和后续问题，仅调换介绍次序。编组、对应与保持身份仍可完成先整体后内部；展开的顺序关系另交串联路径，检查与整合另用留停。缩放不是必要项，何时省略内部、名称是否准确仍由上游明确负责。新增[合成分镜](examples/top-down-chunk.json)与旧的先分后合分开保存，未以新提案覆盖成片或观众记录。

### 五项作品建议怎样落地

| 建议 | 进入哪里、怎样使用 | 没有采纳的强制推论 |
|---|---|---|
| 问题锚点与回扣 | 指南要求按受众说明待解问题或观看目的，检查开场承诺、沿途进展和收束 | 所有内容必须悬疑、故意延迟答案，或九成顶级作品遵循同一结构 |
| 日常感官参照 | 锁定参照增加熟悉度、量纲、换算口径和类比边界检查；用合成长度例演示 | 数值只要换成日常物就必然更易懂，或长度等价意味着用时与难度也等价 |
| 视觉断句与听读分工 | 对应和风格区分字幕、摘要、引文；按语义断行，保留专名、否定和数值单位 | 屏上完整句一概有害、摘要能代替无障碍字幕、机械断行必定使成本翻倍 |
| 语调、听觉表示与全片呼吸 | 对听重音的语义作用，声明编码映射和设备条件，连续回看密集与整合段 | 听觉普遍更快、左右声道自动可达、每隔固定时长必须放空镜或改原声停顿 |
| 复述与总结结晶 | 留停与配方加入可选独立摘要／切片检查，作品层分开记录复述、分享意愿与实际行为 | 所有关系能缩成一帧，一次复述证明长期记忆，或总结帧必然提高传播 |

三面作品审阅不替代原语字典或理解／感受的分开记录，也不建立“合格—世界一流—现象级”的评级量表。用删除对照检查动作经济性：一个元素可以承担多个职责，但删少框、缩短片长或减少原语名称本身不是优越证据。[作品级任务](VALIDATION.md#work-review)

### 核查与实现范围

本轮查阅 W3C 两项媒体解释页、Netflix 字幕通则与 Walker／Nees 的听觉编码综述，分别用于交付条件、平台制作指导与方法边界，未把它们合成普遍学习规律。[核查记录](sources/README.md#sensory-review)

本次只更新方法、注册入口和合成示例。现有 `holds[].visible` 及重叠排程布局检查仍针对可见对象与图表，纯听觉留停和并发映射没有被伪装成机器已支持；具体制作另保存听辨安排与记录。结构检查、真实听辨、无障碍交付、观众理解与传播效果各自认领，不能相互代替。

## 0.5.0 · 让已理解的局部参与下一层推理

2026-11-18。根据[本轮评审原件](sources/mental-model-review-20261118-original.txt)，增加 `video.chunk` 候选组合入口，并细化连续共变、具体与总体往返、预期基线及观看方式。当前集合为十项候选动作与两项候选组合，共十二个入口。文档中的合成分镜尚未渲染，观众表现尚待观察。

### 封装为什么保留为组合

固定已解释的成员、内部关系、短名称、输入输出、必要例外和后续任务，再按同等制作成本重建。编组归属确定整体的边界，对应把展开结构映射到具名简图，保持身份维持收起与后续引用的来处。两张原尺寸静态关键帧即可完成交接，因此缩放可选。原评审指出单独加框、缩小或换标签不足，这些反例尚未排除三项组合的实现。

抽象到何种程度、哪些内部区别可以暂时省略，仍由上游编辑负责并计入成本。组合不会从任意图中自动发现恰当概念。名称若改变条件、输出或性能承诺，应先修正语义输入，再谈收拢。[完整组合卡](PRIMITIVES.md#chunk) · [合成记录](examples/chunked-process.json)

| 固定任务与变化 | 删替检查与适用边界 |
|---|---|
| 把番茄的三个预处理步骤接入炒制 | 具名简图保留输入输出和步骤来处，后续可用整体连接。仅拉远仍可能需要读微字。若改问总用时，需恢复工时及依赖。 |
| 把已解释的温控回路接入设备总图 | 保留测温输入、功率输出与回路范围。若改问为什么振荡，须恢复控制规律、反馈与时延。直接命名“稳定控温”会新增性能判断。 |
| 用已定义的 T＝BA 表示组合变换 | 保留先 A 后 B 的含义和定义域、值域。换成 AB 或只保持行列式都不能保证同一变换。若改问哪步改变方向，再展开。 |

这些对照支持独立检索组合的用途，未证明其组成最少或观众已形成心理组块。未来若给定同样输入，组合仍无法表达一个有用的跨层级判断，应按具体反例重审。

### 其余建议怎样进入现有动作

| 评审建议 | 本轮处理及反例 |
|---|---|
| 连续共变与约束传导 | 对应卡增加已定义关系下的联动，固定规则、范围与其他条件。模型可给连续值，实测离散点须保留证据精度，真实时滞不能因“同步”被删掉。共变本身不证明因果。[规则与实例](PATTERNS.md#rule-instance) |
| 预期基线与预测误差 | 锁定参照允许明确署名、带假设的预测。结果前固定，结果后按同口径比较，允许预测正确。作者猜想、观众回答、零假设与反事实模型分别认领。[预测配方](PATTERNS.md#prediction-baseline) |
| 具象与抽象往返 | 指南补入固定规则后试实例、边界，再回总体关系。有限代值用于检查理解，无法由几个吻合点证明通式。可用静态总览、状态表或连续演示。 |
| 声画先后的方向 | 预备已知对象可画先，给已见现象命名可声先或同步。150～300ms 和 200～400ms 保留为附件候选范围，字幕仍按实际话语同步，不能一律延后或要求所有观众先漏听几个词。 |
| 语义音效、听觉留停与视线跨度 | 在现有定焦、留停与风格中明确辅助提示及声音竞争。检查所需标签、对象与参照的实际阅读路径。提示音须有可见对象，留停可用简短复盘或安静间隔，并核对原声的语气。 |
| 连续观看与暂停核验 | 主张、材料性质、关键判别点与重要限定应在正常播放中可理解。详细出处与补充上下文可暂停核对，仍须能读、能定位。不能把反例或范围限制藏到微字中。[观看检查](VALIDATION.md#viewing-contract) |

### 来源与验证范围

本轮复核 Cowan 的容量综述、Bret Victor 的抽象层级交互文章及 Heer／Robertson 的图表动画论文。它们分别提供特定条件下的容量论证、作者方法示范和图形转场实验依据。约四个组块不等于四个屏上节点，连续运动不自动构成零成本理解，预测失败也不是本版要求的唯一学习条件。[来源核查](sources/README.md#mental-model-review)

现有校验器继续核对入口、组成项、语义对象和时间结构。新增封装记录采用原字段，内部结构收起后的保真、观众能否接续使用及两种观看方式的表现，由[新验证任务](VALIDATION.md#model-building)检验。没有新增认知容量评分、眼动模拟或媒体制作服务。

## 0.4.3 · 把重点段落组织成可跟随的观察过程

2026-11-18。本轮收到[声画叙事升级报告原件](sources/narrative-review-20261118-original.txt)，在 0.4.2 上补充声画预备、跨拍变化、音频读时交接与辅助声音的使用条件。报告所述八轮制作经历、具体节目评分和观众体感尚无本仓库可核验的原始记录。报告对本仓库“销毁组件 A、挂载组件 B”的描述也未附实现依据，本仓库维护的是方法、分镜与检查约定。

### 哪些建议改变了制作决定

| 报告建议 | 合入方式与边界 |
|---|---|
| 先经历机制，后命名概念；图形先为话语作准备 | 对应卡区分已知对象、待解问题与提前揭示的结论。可先演当前话语已描述的动作，再在命名处加术语；现有预告与引语时序继续适用。新添[声画安排表](GUIDE.md#audiovisual-design)，记录触发、对象、继承线索和核对任务。 |
| 从陈述卡片转为建立、冲突、解决 | 将其转成可选的“建立预期 → 观察变化 → 检验解释”配方。变化须有材料支持，疑问尚未解决时保留疑问。人物夸张反应、窗口崩塌或强行胜利会添入未经证实的结果。[重点片段组合](PODCAST-PATTERNS.md#semantic-beat) |
| 单物连续形变，减少反复清空画布 | 身份卡区分同一物变化、复制、替换与隐喻交接。给新的对象保留自己的身份。线条形变、静态对照、有定位线索的切镜均可实现追认，按实际关系选择。 |
| 在原件上找问题，抽出两处高亮对照 | 证据卡补“原件位置 → 观察点 → 比较”的可追溯路径。相同句子只能证明该处重复，要判断整套材料无信息增量，仍须检查其余内容。推镜、划线和碰撞不能放大证据范围。 |
| 扩充音频呼吸停顿，为画面安排读时 | 留停卡与指南增加音轨可编辑范围、候选停顿和重新对齐的交接条件。任务包含剪辑时保留原版与新媒体版本，对听语气并重绑受影响的字幕、说话者和镜头。0.6～1.2 秒作为待试值。 |
| 纸墨微音效、环境声退让与全片能量起伏 | 放入风格层，在有意义的动作处选择声音，按旁白清晰度与最终混音复听。密集段与恢复段由语义和观看任务安排。选择少量重点段落投入制作，并保留完整证据与读时。[辅助声音](STYLE.md#micro-sfx) · [全片疏密](STYLE.md#macro-pacing) |

### 需要收窄的数字与绝对规则

| 原报告中的说法 | 本版处理 |
|---|---|
| 黄金 −300ms、200～400ms 映射效率最高 | 将候选提前量用于样片对照，分别检查预备是否可读、结论是否抢先。相关研究及核查范围单独登记，未确立跨任务通用最优偏移。 |
| 认知负荷按 30／15／40／25 分相加，超过 85 自动降级 | 改为逐拍列出听、读、找、比较和追踪任务，实际检查冲突。未校准的分数不用于自动隐藏字幕、模糊证据或宣布观众负荷合格。 |
| 只能一个坐标点运动、两个运动元素负荷翻倍；彻底删图例和总结栏 | 保留一个明确的主观看任务，它可包含并发或比较的多个对象。标签尽量靠近所指，密集图或全局参照可保留能读懂的图例。 |
| 只留短语、完整句子不上屏、所有原文都做纹理；动效时藏字幕 | 按观看任务选择文字层级。引用、模板、证据和校读材料须可读；字幕保留所需声音信息，必要时与卡片同位呈现。每屏 12～14 字和固定画布字号仅可作排版试值。 |
| 禁用线性、淡入、硬切；贝塞尔等同高阻尼弹簧 | 按运动是否编码时间或数值选择曲线。装饰缓动可试，计量过程先保真。贝塞尔与弹簧是不同的实现方式。 |
| 每四分钟峰值、每三十秒退出白板、音效吸引力提升一半、−26dB 通用目标 | 作为来源作者的未证实主张或不完整参数记录。当前没有相应效果证据；分贝需明确基准与素材电平，节奏须回到实际内容。 |

### 跨题材反例与删替检查

固定任务、材料和同等制作成本，可作三组低成本分镜对照。这些是新构造的检查例，尚未制作样片或记录观众表现。

| 固定观看任务 | 可支持判断的安排 | 单一规则会丢掉什么 |
|---|---|---|
| 两辆恒速车何时追上 | 同一时间尺度下，两车按各自恒定速度同时移动，保留共同位置参照；也可用静态位置表核对 | 只动一辆或给两车任意弹簧缓动，会改变相对运动；保持身份、锁定参照和呈现时间关系已有各自职责。 |
| 修改 Current 会不会改掉历史快照 | Current 继续存在，新快照另具身份；改 Current 后让观众同时核对两份 | 把 Current 连续变成快照会丢失母本。“一镜到底”不能替代派生关系。 |
| 读出诗句中的修订字及其语气 | 原句、改字、朗读归属可辨；按实际朗读安排字幕与读时 | 原句模糊化或删必要字幕会失去核对对象。增加停顿会改变朗读节奏，需对听新版并重绑画面。 |

现有十项候选动作及组合入口可表达以上任务，本轮增加的是选用条件与配方。源附件逐字保存，研究与作者经验按[来源核查](sources/README.md#narrative-review)限定范围。方法、检索入口和检查清单已更新，认知评分、自动混音或眼动审计尚无实现，实际创作效果待制作项目验证。

## 0.4.2 · 让制作约定经得起正常观看

2026-11-15。用户提供了一份以 0.4.0 为对象的审片分析，本次接在 0.4.1 后修订。反馈按问题保存为[消息摘录](sources/viewer-friction-feedback-20261115.json)，其中时码、盲测与比例均属转述。尚未取得所指成片版本、原始观众回答和测试条件。本轮选择细化既有动作的条件与制作检查，十个候选动作及组合入口继续作为候选集合使用。

| 反馈中的困难 | 合入位置与采用条件 | 相邻反例与边界 |
|---|---|---|
| 审计备注占据卡片副标题 | 对应卡交代正文任务；证据卡与[观众文案](STYLE.md#viewer-copy)区分内部来源记录、必要披露和自然文案。保留预告、回顾、编辑示例的可辨归属。 | 拟真重演只有纸纹和光标，仍可能被误当实录。保留“操作演示”等必要提示；机器枚举不自动拼为副标题。介绍审校流程时，术语自身也可能是讲解对象，须按当前主张判断。 |

这些对照是本轮构造的反例，尚未渲染或交给真实观众。固定所问任务、已有材料和同等制作成本，只替换一种呈现选择，检查是否丢失必要信息。

| 固定任务 | 可以保留的选择 | 会丢失或误添什么 |
|---|---|---|
| 展示三步实验记录模板的版式 | 三个具名区块写“条件／观察／结论” | 填入无关医学段落会增添另一组待阅读主张；只用无名横线则不清楚区块职责。 |

## 0.3.2 · 换掉题材，检查动作还能否单独使用

上一版把“话音落后一次放出模板、字幕排进卡内”写进了留停卡，也在证据卡的最小实现里指定了课件对象树。这些做法分别留在字幕、提问卡和课件配方。留停只需给足观察稳定结果的机会，证据落地只要求结论有可定位、范围相称的依据。呈现时间关系根据要判断的是重叠、速率还是积压来索取材料；对齐比较从所问的维度决定读法。

同一检查也用于原有动作。无旁白的影片可以借一个可见事件交接焦点；一辆车驶离原位，仍能凭车身特征追认；上一步退出画面后，下一步只要保有方向与条件，路径依然可重建；两份静态地图也需要同一把比例尺。这四个反例分别收窄了定焦、保持身份、串联路径和锁定参照的必要条件。

**合成分镜：两座展馆在周三什么时候同时开放？** 给定同一当地时间下的两条示例记录，甲馆 09:00–12:00，乙馆 11:00–16:00。让观众指出两馆都开放的时段。用同尺时间带，或用两行带馆名的起止表，都能据同一输入得出 11:00–12:00。删掉乙馆的开馆时刻，只留“两馆周三都开”，交集便无从确定；换视频主题或图形样式均无法补回这个信息。

换一个问题，所需动作也随之变化。若问哪馆开放时间长，可让两行直接显示同单位的 3 小时、5 小时，供对齐比较。若问“甲馆整周都没有夜场”，一张周三时刻表只覆盖周三。若完整时刻表已保持可读，观众有时间找交集，就可直接转场；刚显出第二行便切走，则可补一次留停。这里检查的是分镜能否承载判断。两个场馆和时段均为虚构，尚无观众实测。

## 校正评审里的投机采样分镜

这是评审者提供的纸上压力测试。要让它同时解释速度和分布，至少需要两幅各有任务的图。

**图一回答“哪些步骤重叠”。** 先在同一时标上画出草稿模型逐个提出候选，再画目标模型并行计算各候选前缀下的分布。若第 3 个位置首次被拒绝，保留前两个已接受的 token，丢弃依赖旧前缀的后续草稿，并在第 3 个位置从校正分布补采。若全接受，则从目标分布多采一个。时间轴若没有硬件与采样记录，就以“顺序／并行示意”标明。墙钟耗时包括起草成本，也受接受率、硬件与并行计算成本影响。四个等宽格不足以证明提速四倍。[算法 1、§3.3](https://proceedings.mlr.press/v202/leviathan23a/leviathan23a.pdf)

**删替检查。** 遮掉时间尺，只保留带箭头的流程，仍看得出先后，却读不出耗时；静态时间带也能把基准补回来。去掉词槽的稳定标签，跨快照的连线可以重新配对，但需要逐个追踪。去掉“同一轮验证”的作用边界，多词同时亮起仍不足以交代是不是同一轮计算。这三项是分镜语义对照，其阅读成本需另测。

**图二回答“为何仍服从目标分布”。** 固定同一个前缀，用两个可能的下一 token 做合成算例。设草稿给甲、乙的概率是 0.8、0.2，目标是 0.4、0.6。甲的草稿保留一半，留下 0.4；乙的草稿全收，留下 0.2。被拒的 0.4 按正残差分布全部补到乙，最终就是 0.4、0.6。推导帧保留“0.2 原来保留”“0.4 拒收后补入”的标记与共同概率尺。到判断等量的末帧，甲和乙各占一行，左列写目标、右列写校正后的总量。两列分别用同尺同轮廓读出甲 0.4、乙 0.6；乙的来源明细在等高外框下保留。只看末帧能逐项比数，回看上一步还能追出每份概率的去向。一次“很快”换成“极快”的动画只能举例，不能单靠那一次结果推出分布相同。一般情形的接受率为 min(1, p(x)/q(x))，拒收后按归一化的正差 (p−q)⁺ 抽样。[§2.3、附录 A.1](https://proceedings.mlr.press/v202/leviathan23a/leviathan23a.pdf)

## 0.3.1 · 训练分镜里，哪两格通信与计算重叠？

2026-11-15。新评审提出用四个微批（micro-batch）解释 PyTorch DDP 的梯度累积与分桶同步。“第一个微批绝不触发跨卡梯度同步”会画错第一帧。常规 DDP 默认每次反向传播都做梯度同步，首个微批也可触发。以下另选一种配置：前三次各自的 **forward 和 backward 一起放入** `no_sync()`，第四次正常运行。这里暂缓的仅是 DDP 梯度归约；模型的缓冲区广播、SyncBatchNorm 或显式集合通信各有触发条件。图上只画梯度归约轨，不能把整机网络画成断开。[PyTorch 调优指南](https://docs.pytorch.org/tutorials/recipes/recipes/tuning_guide.html) · [DDP 2.9 API](https://docs.pytorch.org/docs/2.9/generated/torch.nn.parallel.DistributedDataParallel.html)

| 关键帧及拟用成片秒 | 画什么 | 观众应能指出什么 |
|---|---|---|
| ① 0–8 秒，同一参数的本地累积 | 固定某个 rank 上参数 θ 的逻辑梯度标签。任选一分量，三次示例贡献依次为 +2、−1、+0.5，局部累计值为 2、1、1.5；另在角落写“已处理 3/4 个微批”。 | 保持身份让人跟踪同一参数的梯度。3/4 是次数进度；数值可下降。不能凭这一个槽推算整机分配了几份缓冲或峰值显存。 |
| ② 8–16 秒，桶何时可以发 | 为第四次 backward 预设 A、B 两个示意桶，让各参数梯度按实际依赖依次就绪；这里只选全部参数参与、常规有序归约的情形。桶内最后一个梯度就绪时标“齐”。到各 rank 都遵循的桶索引顺序才标“发起”。 | 桶按参数梯度组织，实际边界不必是连续若干层。A 的归约可异步发起，程序随后继续计算 B。某桶先齐、调用已提交、设备上已完成是三个不同状态。 |

**调用清单。** 四帧依次用到保持身份、锁定参照、编组归属、定焦、呈现时间关系、留停，共六个不同动作，另调一次对齐比较组合。若在末帧加入实测 trace 才另调证据落地。上表的 34 秒为片段计划时长，下表的时间格表示图内过程。

|---|---|---|---|---|---|

**删替与边界。** 只留“算 A → 发 A”的依赖箭头，两种排程都能满足它；需恢复共同时间尺与各事件身份和起止，才能复算 10−8＝2。展开“对齐比较”时仍要交代两边的工作量；若一边改为更低精度，终点差便混入通信字节变化。去掉首帧的 θ 标识，三项贡献便失去归属；给三项都标回 θ，就可用静态排版恢复它们到同一参数的映射。额外制作工时没有测量。若设备竞争带宽、某个 rank 晚到或桶组成变化，应以对应训练记录重画区间。此例只有合成分镜和纸上删替，未取得训练 trace、渲染片段或观众结果。[归约设计、论文、固定版本源码与 Profiler 的核对记录](sources/bucket-review-references-20261115.json)

## 两块得分怎样合成同一个 Softmax 分母？

2026-11-15。评审给出的得分行是 `[1, 3 | 2, 4]`。要解释的是怎样保留每块相对于局部最大值的**指数和**，换到共同基准后得到整行的稳定归一化分母。若要讲注意力的加权分子，还需要每个位置的值向量 vᵢ，累积量会成为 Σ exp(xᵢ−m) vᵢ。本例只有得分，镜头聚焦分母 d。[原论文算法 3、§3.1 式 (4)](https://arxiv.org/pdf/1805.02867v2) · [FlashAttention 算法 1](https://arxiv.org/pdf/2205.14135)

给每个非空、得分有限的块一对数：m 是块内最大值，d 是以它为基准的 Σ exp(xᵢ−m)。合并两块 A、B 先取共同最大值 M＝max(mA, mB)，再算 **d＝dA × exp(mA−M)＋dB × exp(mB−M)**。两个因子都写出来，较大最大值那一侧的因子恰为 1；两侧相等时都为 1。

| 关键帧（片段拟用时间） | 要看清的一步 | 可复核的结果 |
|---|---|---|
| ① 0–8 秒，辨认基准 | 编组两块，保留原输入位置。A 为 [1,3]，mA＝3；B 为 [2,4]，mB＝4。两个槽都标上“相对于本块最大值”。 | 两个局部和恰好都是 1＋exp(−2) ≈ 1.135335。基准不同，此刻直接相加会算错。 |
| ② 8–18 秒，换到 4 | 旧基准 3 和新基准 4 同时可见。让 A 槽显示乘 exp(−1)，B 槽显示乘 1。此前保留的两个块摘要已足够合并。 | A 贡献约 0.417667，B 贡献约 1.135335。原位追踪的是逻辑摘要，不要求数据存于同一物理地址。 |
| ③ 18–26 秒，按同序判读 | 上行从原输入直接减 4，下行用两块换算后的贡献。保留推导行，再让两边各自把总数写在同名字段下。 | 两行同得 exp(−3)＋exp(−1)＋exp(−2)＋1 ≈ **1.553002**。符号式在实数算术中恒等，小数为取近似。 |
| ④ 26–32 秒，倒过来检验 | 固定原行各位置，改为先读 [2,4]，再读 [1,3]。留停，让观众判断这次该缩哪一块，然后显示因子。 | 旧最大值仍是 4，旧槽乘 1，新块乘 exp(3−4)。同两项相加，分母不变。把“遇到新块就缩旧槽”背成口诀的人，会在这一步缩错。 |

**纸上删替。** 遮掉两个局部基准，只留“×0.368”，便无法解释为什么缩的是这一块；旁边写回 3、4 和共同的 M 就能恢复。拿掉槽位移动，静态列出“块名／旧基准／转到 M 后的贡献”，仍能从已有摘要完成合并，原位动画可以省。若镜头改为重读 A 的全部得分，虽能重算出分母，却失去了此步只需摘要的解释。最后盖住两侧推导，用同序的最终展开式逐项核对，避免把显示小数相同误当恒等式的证明。

**查出缩错块的反例。** 第一帧的 dA、dB 恰好相等。如果交换两块的缩放标签，误算的总数仍约为 1.553002，只验总数会漏错。换一行 `[0 | 5,5]`，请读者给 A、B 各填一个缩放因子，再核总数。A 的 (m,d)＝(0,1)，B 的 (m,d)＝(5,2)；共同基准是 5。正确的两项贡献为 exp(−5) 和 2，合计约 **2.006738**；把同一因子误乘给 B 则得到 1＋2 exp(−5) ≈ **1.013476**。交换两块的出场顺序后，仍应把缩放标签贴回得分为 0 的那一块。

**“一遍”数到哪里。** 论文算法 2 用两遍先求最大值再求指数和，算法 3 把这两步合成一遍，得到最终 (M,d)。两算法随后都有计算各位置概率 yᵢ＝exp(xᵢ−M)/d 的输出循环。块摘要的合并公式没有承诺具体内核只读一次 HBM。浮点乘加、指数与求和顺序可能带来舍入差异；论文的 V100 基准也只覆盖其实现、精度和批量。此处复算了两种读序的合成数字，未运行硬件基准、渲染分镜或收集观众结果。[来源、章节与适用范围](sources/online-normalizer-references-20261115.json)
