# 视频呈现原语 · v0.1

**把观众需要理解的关系、需要经历的变化和想获得的感受，转成可制作、可检查的呈现动作。**

这是独立的视频领域。当前版本 `0.1.0` 收录十项**候选**原语，面向中文知识短片、播客对谈、课程与 DIY 教程。数量暂定，不宣称已找到最小完备集合。一个静态比较画面、一次留停或一段有目的的声音留白，都可能比新增运动更适合当前任务。

## 从任务进入

| 你现在要做什么 | 阅读入口 | 得到什么 |
|---|---|---|
| 觉得片段单调、难懂，但不知道改哪里 | [使用指南](GUIDE.md) | 具体困难到呈现动作的路由及制作顺序 |
| 查一个动作怎样用、何时不该用 | [候选原语卡](PRIMITIVES.md) | 输入、操作、输出、反例与最小检查 |
| 把动作组合成一段可制作分镜 | [组合配方](PATTERNS.md) | 三个具体情境、时间安排与机器记录 |
| 想要安静、空旷、清新又有表现力 | [风格与声画分工](STYLE.md) | 空间、运动、人物、字幕与声音的职责 |
| 要判断做完了什么、是否有效 | [验证方法](VALIDATION.md) | 来源、实施、理解、审美及无障碍的独立记录 |
| 想核对材料与本次新增解释 | [来源说明](sources/README.md) | 原始报告、引文边界和少量一级来源复核 |

## 五层分工

| 层 | 回答的问题 | 示例 |
|---|---|---|
| 原则 | 为什么这样组织信息或感受？ | 降低竞争、关系清楚、变化可检视；是取舍依据 |
| 原语 | 对给定输入做哪个可复用呈现操作？ | 定焦、对应、保持身份、留停 |
| 组合配方 | 多个动作怎样按时间合作？ | 锁定共同目标 → 对齐比较 → 定焦差异 → 留停 |
| 素材与风格 | 世界长什么样、听起来怎样？ | 海景、地平线、留白、材质、色彩、环境声 |
| 实现 | 用什么制作与渲染？ | Remotion 时间线、SVG、镜头、蒙版、剪辑、录屏 |

验证贯穿上述五层，不是做完特效才追加的阶段。海景、卡片、粒子、弹簧和 3D 不自动成为原语；要先说清它们承担什么作用。

## 两条评价线分别成立

| 评价线 | 要回答的问题 | 可用检查 |
|---|---|---|
| 理解与接受 | 观众能否定位对象、重建关系、解释变化、用于新情境？ | 自由复述、配对、关系重建、预测、迁移 |
| 视觉表现与感受 | 是否有空间、节奏、舒适、惊喜和记忆画面？ | 具体画面回忆、偏好、疲劳、继续观看意愿 |

事实、关系和可读性错误不能靠高审美评分抵消。理解任务做对也不能代替“观众愿不愿继续看”的调查。这里不生成一个把两条线平均掉的总分。

## 当前十项候选

定焦、对应、对齐比较、编组归属、串联路径、保持身份、锁定参照、改变尺度／视点、留停成像、证据落地。完整定义与稳定 ID 见[原语卡](PRIMITIVES.md)。

维护时先检验是否只是既有动作的参数变化，再决定新增、合并或拆分。对齐比较是否应降为配方、尺度与视点是否需要拆开，都保留为开放问题。
