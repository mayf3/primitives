# 视频呈现原语 · v0.6.3

**把观众需要理解的关系、需要经历的变化和想获得的感受，转成可制作、可检查的呈现动作。**

这是独立的视频领域。当前版本 `0.6.3` 提供**十个候选动作和两个组合入口**，面向中文知识短片、播客对谈、课程与 DIY 教程。数量暂定，不宣称已找到最小完备集合。一个静态比较画面、一次留停或一段有目的的声音留白，都可能比新增运动更适合当前任务。声音本身也可以承担辨认、关系或证据任务。

## 从任务进入

| 你现在要做什么 | 阅读入口 | 得到什么 |
|---|---|---|
| 拿已有片段实际审阅，不想同时翻十二张卡 | [四遍审片](VALIDATION.md#four-pass-review) | 事实范围 → 映射参照 → 连续视听 → 脱离上下文风险；按问题调卡并记录实际发现 |
| 觉得片段单调、难懂，但不知道改哪里 | [使用指南](GUIDE.md) | 具体困难到呈现动作的路由及制作顺序 |
| 查一个动作怎样用、何时不该用 | [候选原语卡](PRIMITIVES.md) | 输入、操作、输出、反例与最小检查 |
| 把动作组合成一段可制作分镜 | [组合配方](PATTERNS.md) | 比较、封装、规则代入及预测等情境、时间安排与机器记录 |
| 把长对谈中的操作、困境或方法演给观众看 | [知识播客六个制作配方](PODCAST-PATTERNS.md) | 从选中整页图片，到四窗长文、分支与原段抽骨架，可据以画关键帧 |
| 想要安静、空旷、清新又有表现力 | [风格与声画分工](STYLE.md) | 空间、运动、人物、字幕与声音的职责 |
| 要判断做完了什么、是否有效 | [验证方法](VALIDATION.md) | 来源、实施、理解、审美及无障碍的独立记录 |
| 审整部作品是否易懂、愿看、可复述 | [作品级检查](VALIDATION.md#work-review) | 按明确受众检查问题回扣、感知通达、疏密和离片复述，不做未校准的等级排名 |
| 单拍清楚，整段却累、机械或仍记住旧说法 | [连续观看复核](VALIDATION.md#whole-work-review) | 理解收益、听感、视觉稳定性、跨拍节律及更正后的检查 |
| 动作都有，却错过证据或把局部看成整体 | [组合次序](GUIDE.md#composition-order) · [边界反例](PATTERNS.md#boundary-cases) | 主张角色随入场，前提先于关键变化，保留分母、走势依据与联合代价 |
| 想核对材料与本次新增解释 | [来源说明](sources/README.md) | 原始报告、引文边界和少量一级来源复核 |

## 五层分工

| 层 | 回答的问题 | 示例 |
|---|---|---|
| 原则 | 为什么这样组织信息或感受？ | 降低竞争、关系清楚、变化可检视；是取舍依据 |
| 原语 | 对给定输入做哪个可复用呈现操作？ | 定焦、对应、保持身份、留停 |
| 组合配方 | 多个动作怎样按时间合作？ | 给出可比条件 → 对齐比较 → 留停总览 |
| 素材与风格 | 世界长什么样、听起来怎样？ | 海景、地平线、留白、材质、色彩、环境声 |
| 实现 | 用什么制作与渲染？ | Remotion 时间线、SVG、镜头、蒙版、剪辑、录屏 |

验证贯穿上述五层，不是做完特效才追加的阶段。海景、卡片、粒子、弹簧和 3D 不自动成为原语；要先说清它们承担什么作用。

## 两条评价线分别成立

| 评价线 | 要回答的问题 | 可用检查 |
|---|---|---|
| 理解与接受 | 观众能否定位对象、重建关系、解释变化、用于新情境？ | 自由复述、配对、关系重建、预测、迁移 |
| 视听表现与感受 | 是否有空间、节奏、舒适、惊喜和记忆片段？ | 具体声画回忆、偏好、疲劳、继续观看意愿 |

事实、关系和可读性错误不能靠高审美评分抵消。理解任务做对也不能代替“观众愿不愿继续看”的调查。这里不生成一个把两条线平均掉的总分。

## 0.6.3 · 短补丁与四遍审片入口

收拢保留主张所依赖的限定，收窄比较不删除背景条件，源时间判断保留剪辑映射。只改三张卡的既有条目，并以四遍扫描组织现有检查。暂缓扩写，优先用真实片段检查触发条件和使用成本；明确错误与可复现反例仍可触发修订。[本轮取舍与稳定基线](REVISIONS.md#review-workflow) · [最小审片记录](VALIDATION.md#review-record)

## 0.6.2 · 组合次序与推断边界

补清首次呈现的主张角色、高密瞬态证据的观察次序、样本分母与未知项、循环走势所需条件，以及带波动和联合代价的比较。规则按任务触发，保留盲观察、教学假设和纯拓扑说明的适用范围，不将认知状态模型或有限反例当作完备性证明。[修订与取舍](REVISIONS.md#operator-boundaries) · [五组检查](VALIDATION.md#boundary-review)

## 0.6.1 · 声音通道、旧主张更正与全片摩擦

补齐编组、路径、身份和视点的听觉适用条件；更正时保住旧主张身份，明确反例、失效范围与当前解释。作品级审阅增加四类实际复核，不将固定节拍、频段、像素位移或响度指标当普遍舒适标准。[修订与取舍](REVISIONS.md#sequence-review) · [更正配方](PATTERNS.md#correction) · [全片复核](VALIDATION.md#whole-work-review)

## 0.6.0 · 通道分工、双向拆合与作品级检查

静音检查只回答适用的视觉与字幕问题，声音本体与听觉编码另做听辨及替代访问检查。封装支持先立整体、首次展开、再收回；检索表显式对应历史编号。新增语义断行、日常参照、问题回扣和离片复述的任务，作品级审阅与十二个动作入口分工。原语可用不代表世界级或传播成功。[边界修订](REVISIONS.md#sensory-review) · [新配方](PATTERNS.md#top-down-chunk) · [感知与作品验证](VALIDATION.md#work-review)

## 0.5.0 · 从展开理解到接续推理

新增 `video.chunk` 封装收拢候选组合，将已解释的子图映射为可追认的具名整体。对应、参照与留停卡补充连续共变、预期基线和两种观看任务，风格层补入视线交接、语义音效与听觉留停。固定输入后用已有动作可以重建封装，故将其列为第二个组合入口。[组合与删替](PRIMITIVES.md#chunk) · [具体分镜](PATTERNS.md#chunk) · [本轮修订](REVISIONS.md#mental-model-review)

## 0.4.3 · 安排可跟随的声画变化

重点段落先写观看任务、语义触发、持续识别线索与核对机会，再选择预备画面、连续形变、停顿及辅助声音。补充原件取证与跨题材反例，将未证实的认知分数和固定时钟改为有条件的样片检查。[吸收与取舍](REVISIONS.md#narrative-review) · [声画安排](GUIDE.md#audiovisual-design) · [验证方法](VALIDATION.md#audiovisual-design)

## 0.4.2 · 减少制作中的观看摩擦

补清结构示意与具体正文的选择、内部记录与观众文案的交接，以及普通信息卡入场、人物避让和跨景别识别。按任务选择必要披露，用实际样片测量时序与遮挡。本次反馈按用户转述保存，仍待回到指定成片核对。[四类反馈与反例](REVISIONS.md#viewer-friction) · [制作检查](VALIDATION.md#viewer-friction)

## 0.4.1 · 独立评审落地

为分拍绘入的静态图区分两种时钟，为事后回顾区分出场时机和引述方式。明确要求同时对读时，可以检查各项共同可见的区间。阈值和分块归一化配方补入能区分对错的输入。[评审与验收记录](REVISIONS.md#independent-review)

## 0.4.0 · 先确定观众听到什么、要从画面读出什么

有原声的分镜用语义话轮绑定屏上文案；无声、待核与已对听的材料各有记录方式。逐事件判断与聚合读数有各自的布局约束。连续曲线跨越临界值，可组合已有的编组归属与锁定参照。[两份评审及处理](REVISIONS.md#audiovisual-and-readout) · [声画分镜](GUIDE.md#narration-alignment) · [连续阈值](PATTERNS.md#continuous-threshold)

## 0.3.2 · 原语如何跨题材使用

原语卡保留观看困难、可替换的呈现操作及验收问题。具体的节目文案、镜头、界面属于配方。以“两座展馆何时同时开放”为例，换成具名时间带或起止表，都能检查原来的判断；拿掉一项关键输入，就不能再得出交集。[换题材与删替检查](REVISIONS.md#transfer-check)

## 0.3.1 · 四种末帧检查

两项活动同起同止，能否分别读出？两个概率总量相同，读数时是否还得替一边做加法？改写模板出现时，原声字幕是否也在要求追读？一次点击选中整图，能把结论说到多大范围？本轮修订动作卡、播客配方和样片检查，并为明确选用泳道的分镜增加同槽碰撞检查。可沿用原有 11 个入口及旧分镜。详见[四项处置与训练分镜](REVISIONS.md#boundary-review)。

## 0.3.0 · 如何选用十个动作与一个组合入口

定焦、对应、编组归属、串联路径、保持身份、锁定参照、改变尺度／视点、留停成像、证据落地、呈现时间关系，各有可单独提问的观看困难。**对齐比较**保留原 ID，改为组合入口，负责带着共同条件调用锁定参照、对应和定焦。详见[定义与反例](PRIMITIVES.md)。

这次补入的时间关系可以用四窗说明。把相同的四条回复画在共同时间轴上。按起止区间分别排成轮流到达和同时到达，两种安排都有四个窗口，只有后者在同一时刻向读者提出四项任务。想说明积压，还要给出同一段时间内的到达量与处理量。末帧留着让人读完，又是另一个观看任务。[四窗分镜](PODCAST-PATTERNS.md#text-overload)

0.2.0 的十个 ID、原语卡锚点和旧 JSON 均可继续使用。复核依据、七项方案的取舍和投机采样反例见[版本评审](REVISIONS.md)。

## 0.2.0 修订 · 2026-11-15

《新录音44》的两段审片反馈提出三个会影响分镜的判断：观众需要读出什么，画面怎样让人认出是谁在说或哪个对象在变，旁白何时已经进入下一件事。本版据此细化定焦、对应、保持身份、留停成像、证据落地五张卡。十个候选 ID 与既有分镜格式继续适用。

例如，拿掉四窗口的滚动，静态并排仍能交代有四项任务；要表现回复来得比人读得快，才需要让各窗在读者看完前继续涌入新段。反过来，一次慢推镜无法告诉观众点中的是图还是字。具体任务决定用哪个动作，组件放在[播客配方](PODCAST-PATTERNS.md)中复用。配方里的文案和镜头是编辑提案，时间点来自本次反馈。本轮核对的是[一手资料](sources/README.md#podcast-review)，节目源片、字幕和观众留存尚未核验。
