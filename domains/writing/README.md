# 写作原语

**版本：0.1.0 · 2026-11-13 · 整合候选，待效果验证。**

从当前要写或要改的文字出发，用少量创作动作解决具体困难。后台按需保留“材料—新解释—成稿”的来源与版本联系，让创作能够继续，也让修改可以复查。

适用于中文非虚构、技术长文、经验分享、演讲、口播和对谈稿；文学、审美或陪伴类作品按作者自己的目标判断。固定材料改写与获准的自由虚构分别处理。

## 从你的问题开始

| 当前需要 | 入口 | 会得到什么 |
|---|---|---|
| 想写，但还不知道从哪里讲 | [选切口](ACTIONS.md#choose-angle)、[找材料与标缺口](ACTIONS.md#find-material) | 一个材料能支撑的切口，以及能比较的局部试写 |
| 内容都有了，但读起来散 | [搭中段](ACTIONS.md#shape-middle)、[接关系](ACTIONS.md#connect-relations) | 各部分的作用、需要补上的联系 |
| 想试一个不同的讲法 | [调选材与揭示顺序](ACTIONS.md#sequence-reveal) | 信息覆盖和讲述次序不同的候选，及其取舍 |
| 口播生硬、角色像在念同一份提纲 | [调声音](ACTIONS.md#tune-voice) | 保留事实与角色差异的局部表达 |
| 已知道具体哪里要改 | [定向修补](ACTIONS.md#targeted-revision) | 有准确原句锚点的修改 |
| 多轮越改越失真，或不知道何时停 | [回查与停笔](ACTIONS.md#review-and-stop) | 前轮修复的核对、保留项和停止理由 |

日常先读 [使用指南](GUIDE.md)。八个动作是本次整理的可调用动作集，既不是必须走完的八步，也不是写作能力的穷尽分类。只改一句时，直接改那一句；需要时再回来补材料、调整结构或比较切口。

## 共同保护的内容

材料中的事实、范围、确定性、说话人归属和现实因果不能因润色而悄悄改变。作者可以提出新的解释，也可以改变写作方向；新增解释保留自身身份，改变方向按实际授权记录，不能回头改写原材料来让它们看似一致。

表达不必逐字照搬材料。允许同义改写、自然衔接、拆合句、选材与重排；先辨认重要原句承担的事实、限定、语气或铺垫，修改后让这些作用有合适的承接。具体取舍可以不同，不追求唯一的标准写法。

## 来源和当前状态

本模块以 `mayf3/writing-primitives` 的 main 与未合并 PR #1 候选为来源，并按已经提出的“前台创作动作、后台按需追溯”方向重新整理。**原仓库的候选尚未完成这一步重构；八动作入口与追溯说明属于本次整合内容。** 准确提交、保留规则和差异见 [迁移记录](MIGRATION.md)。

本仓库是此整合版后续方法维护的入口。原仓库运行和历史保持各自身份，没有自动双向同步。本域可以独立阅读，不依赖其他领域的对象、状态或执行器。

当前没有本整合版的模型比较实验或真人读者验证。源快照完整性、链接和索引检查只能证明相应结构可读、可追溯；不能证明文字更自然、更吸引人或写作效率更高。日常仍可依据材料、作者判断和有限反馈选稿，记录实际依据即可。
