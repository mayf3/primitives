# 设计与交互原语

这一领域收录可以改变信息、选择或反馈呈现方式的具体动作，帮助读者理解内容、作出选择和完成行动。

当前 **0.2.0** 保留 **10 个候选原语、4 个组合模式**。数量尚未证明最简，日常也无需逐项应用。先在[调用指南](GUIDE.md)中找到具体困难，再查看[原语卡片](PRIMITIVES.md)的动作、边界与检查方法。

## 什么属于这个领域

原语是“遇到一种可描述的理解或操作困难，可以做什么改变”。本版采用的粒度是：一个明确困难、一个连贯的干预目标、可界定的实现分支。多个独立目标组合成模式；暂不宣称存在理论上不可再分的最小集合。它与其余层次分开：

| 层次 | 作用 | 例子 |
|---|---|---|
| 认知机制 | 解释困难可能从何而来 | 工作记忆、信息线索、视觉分组 |
| 原则 | 表达总体目标 | 清晰、一致、可控制 |
| 启发式 | 提供诊断问题 | 用户知道自己在哪吗？ |
| 原语 | 提供可复用改变 | 预告入口结果 |
| 模式 | 为一个反复出现的情境组合动作 | 学习路线 |
| 组件 | 实现具体呈现 | 链接、步骤条、表格 |

这六层是原报告的综合框架，不能当作某篇论文直接提出的分类。设计原语也不等于任务、人生活动或界面组件。页面、路线、交互状态及无障碍约束保留设计领域自己的语义；本模块没有其他领域模块依赖。

## 版本和证据边界

本模块于 **2026-11-13** 从 `0.1.0` 升为 `0.2.0`：追加用户提供的独立评审原文，修订位置、后继选择、必要条件、关系表示、反馈与恢复的边界，新增任务终点接续模式。原有机器 ID 与锚点保留；机器目录仍只登记十个动作，模式经指南和关联卡片进入。完整差异与兼容影响见[版本评审](REVISIONS.md)。

- 原报告包含十个原语的总表，其中四项有较完整卡片。其余六项在本次整理中补足了可操作说明；各卡片分别标明哪些是增补。
- 原报告的“当前”“本次核对”指原研究时点。原始研究日期无法从上传文本确定，本次未重新走查网站。
- 原报告明确说真实用户观察为零。这里提供的是方法、研究材料和待验证应用，不能宣称已经提高真实用户表现。
- 外部来源由附录导入，状态是 `imported-unchecked`。原会话中的引用令牌不能在 GitHub 独立解析；没有明确 URL 的令牌不强行匹配。
- 后续评审属于结构分析与合成案例推演。“覆盖 90% 以上”“9 项已最简”及固定画图阈值未获相应证据，本版不将其采纳为事实或规则。
- 来源核对、实际实施和用户验证分别记录，规则见[验证与状态](VALIDATION.md)。

## 本域保留的边界

不把“减少点击”“每页只能一个主动作”“降低认知负担”“卡片化内容”“知识图谱化”新增为原语。“让选择可识别”是说明性表达，也不是新的独立原语。原报告第 283–296 行说明了排除、降级或暂缓这些候选的原因。普通举例可以用于补足说明，不自动归入关系外化，也不因此要求加载其他领域。

原语的有效性需要具体任务中的观察。键盘、焦点、组件语义、响应式布局与无障碍技术验收另行执行；内容易读或原语应用合理不等于技术合规。
