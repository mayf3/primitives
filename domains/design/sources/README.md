## 哪些可以据此声称

- 可以确认上传报告包含哪些定义、建议、原报告自述的观察和外部来源 URL。
- 本次没有打开报告中的外部页面核实主张，没有重新走查网站，也没有进行真实用户测试。
- 原报告的“当前”“本次现场核对”仅描述原研究时点；报告自述的网页情况在这里作为历史来源材料保存。
- 原报告第 110 行说真实用户观察为零。对新手行为的预测是设计推断，不是已经观察到的用户事实。
- 原报告关于学习站的若干问题明确为历史材料、本次未复现，不能在整合后写成新发现。

## 外部引用如何处理

原文本包含 `turn…` 形式的会话引用令牌。在原会话之外，它们无法独立解析为永久来源。`references.json` 只根据附录的明确 URL 登记条目，并记录该附录行出现的令牌。

同一篇材料可能有多个令牌；部分正文令牌在附录没有对应项。未明确对应的令牌保留在 `unresolved_citation_tokens`，不靠标题相似或编号相邻强配 URL。附录令牌的登记也不证明对应网页内容已经核对。

来源表 ID、导入状态和类型分组是本次整理新增。条目保留原报告对来源类型的描述；它不是本次独立评定的研究质量结论。
