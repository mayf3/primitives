# 冻结认知原则（V0）

以下四条原则在 V0 冻结，是审问与决策的固定判据。本轮不得修改、增删；变更属于版本级动作，须在新版设计文档中显式提出。

- **P1 资源不能生成任务，只有目标可以生成任务。**
- **P2 努力只能证明付出，不能证明方向正确。**
- **P3 休息不是未利用资源，而是战略判断力的基础设施。**
- **P4 认知改变不以"我被说服了"为完成，而以相同诱因再次出现时产生不同选择为证据。**

## 判据用法（审问者必引）

| 原则 | 检验对象 | 典型应用 |
|---|---|---|
| P1 | "等状态好了 / 有空了 / 学完再说"类 CLAIM | 任务只能从 GOAL 推出；把任务生成权交给"状态"或"资源"即违例 |
| P2 | 学习量、工时、工具投入 | 投入只产生新 OBSERVATION，不构成方向正确的证据 |
| P3 | 熬夜刷手机等"伪休息" | 既非项目推进也非恢复，判定为侵蚀次日判断力 |
| P4 | 每条 TEST 型 DECISION | 必须写明：相同诱因、不同选择、将产生的新 OBSERVATION |
