# 学习原语

**围绕学习者要获得的能力，选择能帮助其形成、运用并检验理解的局部操作。判断依据是指定条件下的表现，而不是浏览了多少材料。**

版本 **0.1.0**，整理日期 **2026-11-14**。本版是研究输入经过边界审查后的工作候选：八个候选操作，加一个“说明依据”的专门任务入口。**九个可查找地址不等于九条独立公理，也不是已经证明最简或完备的集合。**

## 本域直接负责什么

处理“谁要学会什么、需要什么关系和过程、怎样练、获得什么反馈、在什么条件下表现如何”。页面布局、视频风格、学习管理系统都可以承载这些操作，但它们不是本域的原语本身。

先约定目标：理解一个概念、完成眼前任务、独立解决变式、长期保持，是不同承诺。只承诺导听、查资料或完成一次操作时，不必把所有操作都塞进页面。只有声称某种能力时，才需要相应的表现依据。

## 本版状态

- **定义**：已整理输入输出、边界、相邻反例和删并假设；没有完成形式最小性证明。
- **来源**：研究原文按字节保留；选用论据另查可解析的一手页面。论文摘要核验、实践指南、产品结构参考和技术文档分别标注，原报告的旧会话引用未恢复。
- **实施**：本模块是方法文档与合成例子。写入仓库不表示任一课程或网站已经实现它。
- **效果**：本版没有真实学习者观察。所有应用提案保持 `user_validation_status: untested`，未来结果须绑定具体任务与条件。

检索示例：

```bash
python3 tools/primitives.py list --domain learning
python3 tools/primitives.py find '不知道是什么' --domain learning
python3 tools/primitives.py show learning.relation-model
python3 tools/primitives.py show learning.explain-reasoning
```

后续修订由新任务中的遗漏、重复责任或调用困难触发。不因课程有六步就发明六项原语，也不为保住当前数量而把必要判断藏进参数。
