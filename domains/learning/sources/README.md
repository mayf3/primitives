# 学习领域来源与核验边界

本领域以用户上传的《从陌生、误解与依赖帮助，到能够解释、操作、判断与迁移：学习原语研究与 Remotion 学习路径审查》为研究输入，导入及本轮来源核验日期为 **2026-11-14**。原文自述的核查日期不等于可独立确认的写作日期；清单中的 `original_date` 保持 `unknown`。

## 原文、文献核验与方法提案分开

- [research-original.txt](research-original.txt) 按字节保存上传文件，原文件名、字节数和 SHA-256 见 [manifest.json](manifest.json)。不修正其中的措辞、旧引用或结论；后续解释写入工作文档。
- [references.json](references.json) 是本轮独立识别并有限核验的 **8 项核心来源与 1 项补充研究**，不声称恢复了报告的完整参考书目。
- 原文 `turn…search…`、`turn…view…` 等会话引用保留为 **unresolved**。找到同名论文不等于恢复旧引用；本次记录不将两者强配。
- 论文核验以出版社、作者机构或 PubMed 提供的原始摘要及书目信息为限，**没有完成论文全文复核**。IES 核对官方概览与推荐等级；MDN 和 Remotion 核对相关官方网页。
- 来源核对、原语构造、网站实施、真实学习者表现分别报告。来源提供支持与限制，不能证明候选原语数量最少、覆盖完备，或本站改版已经有效。

### L-S01｜概念预训练

**Mayer, R. E., Mathias, A., & Wetzell, K. (2002).** *Fostering understanding of multimedia messages through pre-training: Evidence for a two-stage theory of mental model construction.* **Journal of Experimental Psychology: Applied, 8**(3), 147–154.

[DOI: 10.1037/1076-898X.8.3.147](https://doi.org/10.1037/1076-898X.8.3.147) · [PubMed 原始摘要与书目](https://pubmed.ncbi.nlm.nih.gov/12240927/)

**核验范围：** 原始摘要与元数据；未复核全文。研究包含汽车制动系统和打气筒的多媒体解释。

**可支持：** 对缺少必要基础的学习者，先辨认关键部件及状态，可帮助理解后续复杂过程。**不支持：** 所有课程必须先完整讲理论、所有学习者必须先读同一介绍，或某个 Remotion 页面改版已被直接验证。把“最低必要概念”作为入口条件，是本站设计解释。

<a id="l-s02"></a>
### L-S02｜从例题过渡到自行解题

**Renkl, A., Atkinson, R. K., Maier, U. H., & Staley, R. (2002).** *From example study to problem solving: Smooth transitions help learning.* **Journal of Experimental Education, 70**(4), 293–315.

[DOI: 10.1080/00220970209599510](https://doi.org/10.1080/00220970209599510) · [作者机构记录](https://asu.elsevierpure.com/en/publications/from-example-study-to-problem-solving-smooth-transitions-help-lea/)

**核验范围：** 作者机构提供的原始摘要与书目；未复核全文。研究含一次实地实验和两次实验室实验。

**可支持：** 从完整例题逐步移除解题步骤，过渡到自行解题；研究至少在近迁移上报告收益。**不支持：** 渐隐必然带来远迁移，或所有任务都应同时隐藏全部帮助。远迁移相关表述需结合 [L-S09](#l-s09)，并保留组合条件与任务范围。

<a id="l-s03"></a>
### L-S03｜记忆检索

**Karpicke, J. D., & Roediger, H. L., III. (2008).** *The critical importance of retrieval for learning.* **Science, 319**(5865), 966–968.

[DOI: 10.1126/science.1152408](https://doi.org/10.1126/science.1152408) · [PubMed 原始摘要与书目](https://pubmed.ncbi.nlm.nih.gov/18276894/)

**核验范围：** 原始摘要与元数据；未复核全文。实验采用外语词汇学习任务。

**可支持：** 在所测条件下，首次答对后继续进行记忆检索可以改善延迟回忆。**不支持：** 任何点击、选择、修改参数、操作或产出都是检索；Agent 交付成品就证明学习者学会；重复阅读在所有情境都无效。

“要求学习者产生回应”是更广的设计操作。检索、解释、预测、操作、创作需要各自的任务定义与证据，不能共用这篇论文作无差别背书。

<a id="l-s04"></a>
### L-S04｜练习间隔与保持时间

**Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006).** *Distributed practice in verbal recall tasks: A review and quantitative synthesis.* **Psychological Bulletin, 132**(3), 354–380.

[DOI: 10.1037/0033-2909.132.3.354](https://doi.org/10.1037/0033-2909.132.3.354) · [PubMed 原始摘要与书目](https://pubmed.ncbi.nlm.nih.gov/16719566/)

**核验范围：** 原始摘要与元数据；未复核全文。综述汇总言语回忆领域的 184 篇文章、317 个实验与 839 项评估。

**可支持：** 练习间隔与目标保持时间共同影响保持效果。**不支持：** 24–72 小时对所有课程最优、结果无条件适用于完整编程项目，或同时改变时间与提示后可把差异单独归于时间。延迟评估本身也不是间隔练习的对照实验。

[DOI: 10.3102/003465430298487](https://doi.org/10.3102/003465430298487) · [出版社摘要与书目](https://journals.sagepub.com/doi/10.3102/003465430298487)

**核验范围：** 出版社原始摘要与元数据；未复核全文。该文为反馈的概念分析与研究综述。

## 整合报告时保留的修订

| 报告中的组合或外推 | 工作文档处理 |
|---|---|
| 将检索与广义产出合称，网站动作扩展到选择、修改和操作 | 将可观察回应作为任务设计，将检索作为有特定记忆要求的子类；记录学习者实际完成的部分及支持条件 |
| “延后无提示再做” | 分别记录时间、提示与任务变化；组合评估可以使用，但不把结果归因于其中单一条件 |
| 渐隐与远迁移 | 区分 L-S02 的近迁移依据与 L-S09 的渐隐加自我解释组合；不作跨领域保证 |
| 24–72 小时再做、固定通过百分比 | 标为试点观察窗口或决策规则，不写成普遍最优、理论阈值或既有验证结果 |
| 最小性或不可删减主张 | 保留为候选构造，按固定任务和成本检验删并，不从有限来源推出已证最小集合 |
| 官方网站的结构示例 | 用于提出实现选择；与学习效果实验、技术事实分开 |

允许什么支持取决于目标能力。目标若是借助文档或 Agent 完成任务，使用这些支持并不自动使评估无效；同时需要说明证据能否支持学习者解释选择、识别错误和调整结果。个人自述、作品验收、网页操作记录与学习能力证据保持各自含义。
