# 从讲稿到视频，再到观看入口

这是**按需使用的跨领域组合**，不是每次制作必须运行的工作流。人生、写作、设计、视频仍各有独立入口；只有本次任务确实跨域才交接材料。

| 任务 | 所属领域 | 输出给谁 |
|---|---|---|
| 判断问题是否值得做、提出待检验的取舍 | [人生](../domains/life/GUIDE.md)，仅在确有该任务时 | 给制作过程明确问题与约束，不搬运个人记录 |
| 把材料组织成可讲述的文字，保留原话与新增解释 | [写作](../domains/writing/GUIDE.md) | 给视频领域提供稿件、事实边界与来源位置 |
| 按时间呈现对象、关系与感受 | [视频](../domains/video/GUIDE.md) | 给项目提供分镜、声画安排及独立验证问题 |
| 让观众知道点开会看到什么、如何定位和继续 | [设计](../domains/design/GUIDE.md) | 给发布项目提供观看入口、导航与操作反馈 |

## 合成实例：把版本管理讲解做成可观看内容

1. **写作。** 使用 `writing.connect-relations` 和 `writing.choose-angle`，围绕“为什么 Current 改了，旧快照还留着”组织一段讲稿。输入中只有示例约定；“这能减少返工”等效果推断另标，不能回填成原材料事实。
2. **视频。** 使用 `video.focus`、`video.group`、`video.identity-preserve`、`video.reference-lock`、`video.correspond`、`video.hold`。生成[Current/Archive 分镜](../domains/video/PATTERNS.md)及[机器记录](../domains/video/examples/current-archive.json)。保持 Current 身份，并把快照画成派生新对象。
3. **设计。** 使用 `design.entry-outcome`、`design.position-progress`，提出“观看 48 秒示例：分清工作稿与历史快照”的入口及章节定位。48 秒是当前计划值；成片没有产出前，发布入口仍是提案，不能声称已可观看。实际时长、字幕和播放器能力由发布项目核实后再使用。

## 交接条件

- 写作 → 视频：包含讲稿版本、原材料位置、新增解释与未解决问题。关系不清的部分先退回核对，不靠图形猜测。
- 视频 → 设计：交付的是计划还是实际成片必须明说；需要真实产物、核实后的时长、内容承诺、字幕及观看限制，才可对外使用完成态文案。
- 验证记录 → 后续判断：仅传递实际观察及版本范围。结构检查或部署成功不产生“观众更理解”的结论；如要把观察接入人生判断，另按该领域的事实与证据关系规则处理。

一个网页里的高亮和一个片段里的定焦可能实现相似，但任务、时序与验证不同；不会因名称或技术相似就合并成同一原语。视频渲染成功也不自动满足网页操作或键盘访问要求。

本组合锁定的模块版本及交接关系见[机器记录](script-to-video.json)。状态为 `synthetic` / `not-run`，没有观众观察。它只是方法交接例，不安装 Remotion 工程，不创建调度或跨仓自动同步。

## 设计 0.2.0 兼容复审

2026-11-13：入口结果的用法不变；`design.position-progress` 在这里仅用于视频章节定位及返回结构，不声称观众读完或掌握，符合“标明位置与阶段”的修订。因此将机器记录固定的设计版本更新为 `0.2.0`，写作和视频版本及未实施、未观察状态保持原义。

## 视频 0.2.0 兼容复审

2026-11-15 复核了 48 秒分镜中的六个视频 ID。Current 在生成快照时继续可见，末段留停供观众对照，符合修订后的身份与留停条件。机器记录随之更新视频版本，交接产物仍为合成分镜。

## 视频 0.3.0 兼容复审

再次核对 48 秒 Current/Archive 分镜。保留母本及新副本用于辨身份，固定项目边界用于定位参照。六个方法 ID 仍然有效，快照生成顺序按既有分镜表达，交接仍为未渲染提案。

## 视频 0.3.1 兼容复审

上述 48 秒分镜保留六个视频 ID，按先后展示生成与归档。可选的事件布局用于需要画出区间的片段，本例沿用原时间安排。

0.3.2 核对同一分镜，末段让观众区分母本与快照，两者可辨后即可转场。这个留停任务无需字幕卡。

## 视频 0.4.0 兼容复审

交接已有原声时，写作端交出所用版本、原话位置、说话者及新增解释。视频端按语义话轮认领屏上文字，成片秒从剪辑后的片段起算。原有 48 秒 Current/Archive 案例按旧计划格式读取，源音轨和字幕锚点仍待核。旧计划进入实际制作时，先选声画状态，再逐项绑定正文。

## 视频 0.4.1 兼容复审

讲稿端交付逐字引文和编辑概括的区分，视频端另定它作同步引述还是回顾。已有 48 秒示例沿用成片时间与既有方法 ID。

## 视频 0.4.2 兼容复审

视频端为结构任务选具名区块，为正文判断取相应材料，并将内部来源记录编辑为必要的观众提示。入场空等、运动遮挡及跨景别身份在实际样片复核。现有 48 秒示例继续采用既有 ID 和计划格式；未声明新机位或入场测量，实际播放结果仍待制作项目记录。

## 视频 0.4.3 兼容复审

稿件与视频共同约定概念的引入顺序、观看任务和读时。若制作任务包含音频剪辑，交接新音轨版本及源位置到成片位置的映射，字幕、语义触发、镜头与发布章节按受影响范围复核。已有 48 秒示例仍按当前稿与派生快照分别认领身份，各方法 ID 可继续使用；没有据本轮建议改动其音轨或生成产物。

## 视频 0.5.0 兼容复审

封装子结构时，稿件端提供整体名称、内部关系、输入输出、必要条件与后续问题，视频端据此建立具名简图及回溯线索。预测内容分别标明作者假设、模型或观众实际回答。面向发布入口，另交连续观看须完成的判断及暂停核验材料的位置和可用方式。既有 48 秒例的六项 ID 与派生语义仍可用，快照不因新增封装入口变成 Current 的缩略状态。

## 视频 0.6.0 兼容复审

稿件交接另含面向受众的待解问题或观看目的、语调与字面不同的必要语境，以及首次给整体时尚未解释的内部关系。视频端按视觉提示、听觉材料或联合判断安排动作，字幕与摘要各自保留职责。发布端明确所支持的视听、字幕或替代版本；独立总结帧、声音样本或切片须携带足够的对象、条件及来源性质。十二个视频入口继续有效；已有 Current／Archive 视觉例不因此变成听觉示例，也不据一次复述认领传播结果。

## 视频 0.6.1 兼容复审

讲稿端在更正处交接旧主张的归属、依据、被反驳或不再适用的范围，以及已知替代解释与尚未知项。视频端保留原身份，另呈现状态与理由；声音身份和视点转换须交代来源与加工，不能据相似音色认领同一人物或同次事件。发布端检查更正后的总结与独立切片是否仍将旧说法当结论。全片复核可以要求回修局部，技术音画修复依制作任务授权进行；既有合成分镜保持未实施状态。

## 视频 0.6.2 兼容复审

讲稿端交接教学假设与事实未决的区别、关键变化所需判据，以及涉及总体、循环走势或多指标取舍时的材料边界。视频端从首次可辨起保持主张角色，把必要观察前提安排在关键变化前，保留选样、未知项与联合条件。发布端另核独立切片的归属，不把跳看测试当任何入口均保证理解。既有 Current／Archive 示例不承担频率推断或动力学预测，六项 ID 与合成、未实施状态继续有效。
